## Описание проекта
Программа представляет собой графическое приложение на базе библиотеки Tkinter, реализующее плавную симуляцию движения частиц дождя в реальном времени. Реализован эффект псевдотрехмерности: капли на дальнем плане обладают меньшей толщиной и скоростью падения, создавая выраженное ощущение глубины сцены. Архитектура проекта выстроена по принципу разделения ответственности между математической моделью частиц и модулем отрисовки.

---

## Функциональные возможности
### Основной функционал
- 🌧️ Непрерывная генерация и падение частиц дождя
- 🧊 Имитация эффекта глубины пространства (3D-эффект за счет градации скорости, длины и толщины)
- 🔄 Бесшовное циклическое пересоздание капель при выходе за нижнюю границу экрана
- ⏱️ Частота обновления кадров ~60 FPS с использованием `root.after`

### Особенности архитектуры
- 🧱 Модульная структура: разделение математики (`RainDropModel`) и холста (`RainRenderer`)
- 📜 Соответствие стандартам PEP 8 и PEP 257
